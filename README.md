# Descripción del repositorio
Este repositorio ha sido desarrollado con el objetivos de explorar los diferentes modelo existentes de Machine Learning supervisados y no supervisados para porblemas tanto de clasificación como de regresión, llegando a profundizar con algún ejemplo de Deep Learning (Ej.:13-recommendation-system.ipynb).

## Estructura
El proyecto está organizado de la siguiente manera:

- **`requirements.txt`** → librerias utilizadas.
- **`data`** → información utilizada en algunos proyectos para entrenar los algoritmos.
- **`src`** → carpeta principal donde se encuentran y desarrollan todos los scripts.
- **`models`** → carpeta donde se almacenan los modelos entrenados. 

## ⚡ Configuración Inicial
**Prerrequisitos**
Tener Python 3.11+ instalado en tu máquina. También necesitarás pip para instalar los paquetes de Python.

**Instalación**
Clona el repositorio del proyecto en tu máquina local.

Navega hasta el directorio del proyecto e instala los paquetes de Python requeridos:

```bash
pip install -r requirements.txt
```

## Trabajando con Datos
Puedes colocar tus conjuntos de datos brutos en el directorio data/raw, conjuntos de datos intermedios en data/interim, y los conjuntos de datos procesados listos para el análisis en data/processed.

Para procesar datos, puedes modificar el script app.py para incluir tus pasos de procesamiento de datos, utilizando pandas para la manipulación y análisis de datos.
